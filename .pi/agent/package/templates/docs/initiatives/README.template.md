# Initiatives

Use `docs/initiatives/` for major features or cross-cutting product work.

## When to use an initiative folder
- new major feature
- ambiguous or cross-cutting work
- work that needs durable PRD/backlog/decision tracking

## Expected structure
- `docs/initiatives/<feature-slug>/prd.md`
- `docs/initiatives/<feature-slug>/backlog.md`
- `docs/initiatives/<feature-slug>/decisions.md`
